# Pasangin — Game Cocokkan Gambar

Game edukasi berbasis HTML, CSS, dan JavaScript murni. Bisa dimainkan di browser laptop maupun HP, tanpa instalasi atau framework.

## Fitur
- 6 level progresif; tiap level menambahkan 3 benda dan tetap menyertakan benda dari level sebelumnya (total 18 benda).
- Foto benda sehari-hari dimuat dari Unsplash.
- Cocokkan pasangan dengan memilih gambar kiri lalu gambar kanan; garis penghubung tampil setelah pasangan benar.
- Penilaian bintang: 3 bintang tanpa kesalahan, 2 bintang dengan 1–2 kesalahan, 1 bintang jika lebih dari 2 kesalahan.
- Layout responsif untuk desktop dan ponsel.

## Menjalankan lokal
Buka `index.html` di browser. Koneksi internet diperlukan untuk memuat foto dari Unsplash.

## Upload ke GitHub Pages
1. Buat repository baru di GitHub.
2. Upload `index.html` dan `README.md` ke root repository.
3. Buka **Settings → Pages**.
4. Pada **Build and deployment**, pilih **Deploy from a branch**.
5. Pilih branch `main` dan folder `/ (root)`, lalu tekan **Save**.
6. Tunggu beberapa menit; GitHub akan menampilkan URL website di bagian Pages.

## Catatan
Foto dimuat dari Unsplash menggunakan URL foto yang ditentukan di `index.html`, jadi perangkat pemain memerlukan koneksi internet. Pastikan memeriksa foto dan atribusi/lisensi yang sesuai dengan kebutuhan tugas kampus sebelum publikasi.
